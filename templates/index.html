Paulina Quintanilla, Daniel Navia, Felipe Moreno, Stephen J. Neethling y Pablo R. Brito-Parada.

01

Proceso integrador

TABLA 2
Gp,i(s) = −0.001018 e−θᵢss

Al aumentar el caudal de salida, baja el nivel. El retardo es de 7, 6 y 3 segundos para las celdas 1, 2 y 3.

hi[k+1] = hi[k] + |k′| (qin,i[k] − vi[k]) Δt

Se extiende el integrador a un balance efectivo. vi[k] = ui[k−θi], qin = (Qfeed, v₁, v₂). El retardo se representa en la actuación de la bomba.

02

Control PI

ECS. 1 Y 7
ui = q₀ + Kc,i ei + Ii + fi
Ii[k] = Ii[k−1] + Kc,iτi ei[k] Δt

e = consigna − nivel medido. q₀ es el sesgo de equilibrio. Se añade saturación del mando e integración condicional para evitar windup. La acción derivativa es cero.

El cálculo usa unidades físicas: cm, segundos y L/min. JavaScript solo presenta los resultados que devuelve Python.
03

Anticipación de caudal

ECS. 7–8
fi[k] = Kff,i (qin,i[k] − qin,i[k−1])

Modo literal, predeterminado: reproduce el término escrito en las ecuaciones 7–8. Si la perturbación se estabiliza, ese término vuelve a cero.

fi[k] = fi[k−1] + Kff,i Δqin,i[k]

Modo sostenido, extensión: acumula los incrementos para compensar un cambio persistente. Es una alternativa didáctica explícita; no se atribuye al código original de los autores.

04

Evaluación

EC. 9
IAEi ≈ Σk=0N−1 |hsp,i[k] − hi[k]| Δt

La web evalúa el nivel real simulado para no confundir ruido del sensor con desempeño. También calcula ISE, error máximo, error final, tiempo en saturación y variación total del mando.

Muestreo y control: 1 s. Integración explícita con flujos constantes por intervalo. Horizonte inicial: 900 s.

SINTONÍA SIMC

Comprueba el punto de partida

Para el integrador ideal: Kc = 1 / [k′(τc + θ)] y τi = 4(τc + θ). El artículo ajustó después los valores experimentalmente.

LECTURA CRÍTICA

Alcance y decisiones del modelo

Datos publicados

Banco de tres celdas de 30 × 30 × 45 cm, tanque de alimentación de 130 L, bombas peristálticas y control mediante PLC/MATLAB. Aire de referencia: 47 L/min por celda. El montaje trabaja con agua, aire y reactivos, sin sólidos.

Supuestos de la simulación

Niveles iniciales, secuencia de consignas y perturbaciones elegidos con fines didácticos. Alimentación prescrita y depósito de retorno no dinámico. No se simulan recuperación mineral, espuma, arrastre de concentrado ni variaciones de aire. Las burbujas son ilustrativas.

Modelo efectivo, no geométrico

La ganancia de la tabla 2 no coincide con la obtenida de un balance ideal usando el área geométrica. Se conserva k′ publicado, sin reemplazarlo silenciosamente por 1/A. El acoplamiento de caudales es una extensión explícita del modelo identificado.

Inconsistencias del documento

La ecuación 4 presenta un primer orden; la tabla 2 presenta integradores. Algunos valores iniciales de SIMC no se obtienen de los datos mostrados. Se priorizan las funciones de transferencia y parámetros finales de la tabla 2.

Medición y saturación

Filtro mediana causal de 10 muestras. Ruido gaussiano opcional con semilla fija 2023, idéntico para ambos ensayos. Límites basados en el extremo de calibración de 28 000 cuentas; no se afirman como el máximo físico de las bombas.

Qué significa la comparación

No hay series originales ni código experimental disponible en el PDF. La validación aquí comprueba la implementación matemática. No reproduce ni valida experimentalmente la figura 14 y no garantiza que feedforward siempre mejore el IAE.

Instrumentación, calibración y preparación del experimento

Señales: entradas y salidas analógicas de 4–20 mA. PLC GE Fanuc IC693ALG223 para sensores e IC693ALG392 para actuadores; comunicación de Proficy/GEHCS con MATLAB.

Bombas, figura 9: Qfeed = 0.0035 · cuentas; Qsalida1 = 0.0029 · cuentas; Qsalida2,3 = 0.0033 · cuentas, en L/min. Las cuentas mostradas en el CSV son una conversión ideal; no hay PLC real conectado.

Sensores, figura 11: h₁ = −0.0018x + 40.1363; h₂ = −0.0019x + 43.8823; h₃ = −0.002x + 41.293, en cm. No se agregan estas calibraciones como una dinámica adicional: el modelo trabaja directamente en cm.

Reactivos del estudio: azul de metileno 10 ppm, MIBC 330 ppm, Flottec F160–10 20 ppm y goma xantana 600 ppm. Se registran como contexto del montaje, sin simular su química.

Las calibraciones y las pruebas de escalón se repitieron por triplicado. Los autores emplearon ensayos de 15 minutos y un periodo de muestreo de 1 segundo. La figura 14 muestra aproximadamente 600 s de las respuestas.

EJECUCIÓN / ENTREGA

Del laboratorio
a cualquier navegador.

Una aplicación HTML con un servidor Python y el modelo disponible para revisión.

01

Ejecutar en la laptop

Instala Python 3.12, extrae el proyecto y abre INICIAR_WINDOWS.bat. La primera ejecución necesita Internet para instalar Flask.

Cuando aparezca el servidor, abre esta dirección en Google Chrome:

http://127.0.0.1:5000

También puedes ejecutar manualmente:

python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py

En macOS o Linux: sh iniciar.sh. El navegador carga la interfaz desde Python; abrir el HTML con doble clic no ejecuta el modelo.

02

Publicar en Render

Sube el contenido del proyecto a un repositorio de GitHub. En Render crea un Web Service con entorno Python 3 y conecta el repositorio.

pip install -r requirements.txtgunicorn --bind 0.0.0.0:$PORT app:app

El archivo render.yaml también permite crear el servicio mediante un Blueprint. La URL pública será la que Render asigne después del despliegue.

Documentación oficial de Render ↗
03

Revisar los modelos

model.py contiene el integrador, los retardos, el PI, el feedforward y las métricas. app.py sirve la interfaz y la API. El modelo también funciona sin Flask:

python simular.py --salida resultado.json

Para comprobar sintaxis y ejecutar las pruebas:

python -m compileall -q .
python -m unittest discover -s tests -v

Python interpreta el código. No necesitas generar un archivo .exe para ejecutar o revisar la simulación.

  4. Compara el feedforward literal y la extensión sostenida.
